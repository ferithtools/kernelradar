# Code of conduct

We follow the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The project commits to a harassment-free, technically focused
collaboration space.

In short:

- Be kind. Critique code, not people.
- Disagreement is fine, sneering is not. Walk away from a thread
  before saying something you'd regret.
- Off-topic political / cultural / personal flame wars belong
  literally anywhere except this issue tracker.
- We don't care who you are outside the project. We do care that
  you act civilly inside it.

If something on the issue tracker, in pull-request reviews, in chat,
or in any other project space crosses the line, **report it**:

- **GitHub abuse report** - fastest, since GitHub can act on accounts:
  [docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
- **Email the maintainer** - `ferithtools@users.noreply.github.com`.

Reports are read by the maintainer only and acted on within 7 days.

Possible responses, ordered by escalation:

1. Quiet word - a private message asking the participant to stop.
2. Public correction in the thread - "this is out of line, please
   stop".
3. Temporary block from the repository.
4. Permanent ban from the project.

We won't run a kangaroo court. Genuine misunderstandings get a
"hey, that came out wrong, can we redo this?" Repeated bad-faith
behaviour gets the door.

The full Covenant text (which has additional language on
attribution, scope, and the four-tier enforcement ladder) is at
the link above and is incorporated into this project by reference.
