# Code of conduct

🇬🇧 **English** · [🇷🇺 Русский](#code-of-conduct--русская-версия)

---

We follow the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The project commits to a harassment-free, technically focused
collaboration space.

In short:

- Be kind. Critique code, not people.
- Disagreement is fine, sneering is not. Walk away from a thread
  before saying something you'd regret.
- Off-topic political / cultural / personal flame wars belong
  literally anywhere except this issue tracker.
- We don't care who you are outside the project. We do care that
  you act civilly inside it.

If something on the issue tracker, in pull-request reviews, in chat,
or in any other project space crosses the line, **report it**:

- **GitHub abuse report** — fastest, since GitHub can act on accounts:
  [docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
- **Email the maintainer** — `ferithtools@users.noreply.github.com`.

Reports are read by the maintainer only and acted on within 7 days.

Possible responses, ordered by escalation:

1. Quiet word — a private message asking the participant to stop.
2. Public correction in the thread — "this is out of line, please
   stop".
3. Temporary block from the repository.
4. Permanent ban from the project.

We won't run a kangaroo court. Genuine misunderstandings get a
"hey, that came out wrong, can we redo this?" Repeated bad-faith
behaviour gets the door.

The full Covenant text (which has additional language on
attribution, scope, and the four-tier enforcement ladder) is at
the link above and is incorporated into this project by reference.

# Code of conduct — русская версия

🇬🇧 [English](#code-of-conduct) · 🇷🇺 **Русский**

---

Проект следует [Contributor Covenant v2.1](https://www.contributor-covenant.org/ru/version/2/1/code_of_conduct/).
Цель — пространство сотрудничества без харассмента, с фокусом на
техническом разговоре.

Коротко:

- Доброжелательно. Критикуй код, не людей.
- Несогласие — нормально, ехидство — нет. Уйди из треда раньше,
  чем напишешь то, о чём пожалеешь.
- Оффтопиковые политические / культурные / личные срачи относятся
  буквально куда угодно, но не в этот issue-tracker.
- Нам всё равно, кто ты вне проекта. Нам важно, чтобы внутри ты
  вёл себя по-человечески.

Если что-то в issue-tracker, ревью pull-request'ов, чате или любом
другом пространстве проекта переходит черту — **сообщи**:

- **GitHub abuse report** — быстрее всего, GitHub может принимать
  меры на уровне аккаунтов:
  [docs.github.com/.../reporting-abuse-or-spam](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
- **Электронная почта maintainer'у** —
  `ferithtools@users.noreply.github.com`.

Сообщения читает только maintainer; реагирует в течение 7 дней.

Возможные реакции, по нарастанию:

1. Тихое слово — приватное сообщение с просьбой остановиться.
2. Публичная коррекция в треде — «это уже за гранью, остановись».
3. Временный блок в репозитории.
4. Перманентный бан из проекта.

«Самосуд» устраивать не будем. Искренние недопонимания закрываются
ответом «извини, не так выразился, давай переделаем». Повторное
недобросовестное поведение получает дверь.

Полный текст Covenant'а (с дополнительными формулировками по
атрибуции, области действия и четырёхступенчатой лестнице
enforcement'а) — по ссылке выше, и включается в этот проект
по ссылке.
